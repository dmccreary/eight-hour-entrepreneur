#### 1. What is the CO.STARTERS Canvas, as this chapter defines it?

<div class="upper-alpha" markdown>
1. A multi-page business plan required before a venture can register with the state
2. A single-page business-design tool made up of 11 linked sections, each holding the answer to one specific, plain-language question about a venture
3. A financial spreadsheet that projects revenue and costs over five years
4. A slide deck template used only during the Session 4 pitch
</div>

??? question "Show Answer"
    The correct answer is **B**. The CO.STARTERS Canvas is a single-page business-design tool made up of 11 linked sections — Customer through Costs — each holding the answer to one specific, plain-language question. Unlike a multi-page business plan, it fits on one sheet by design, so a founder can see their whole business logic at a glance and a peer can review it in under two minutes.

#### 3. What is a canvas block?

<div class="upper-alpha" markdown>
1. A single labeled section of the CO.STARTERS Canvas holding a short, specific answer to one guiding question, sized to fit a large index card
2. A timed group exercise in which participants draft answers individually before comparing with a peer

</div>

??? question "Show Answer"
    The correct answer is **A**. A canvas block is a single labeled section of the CO.STARTERS Canvas holding a short, specific answer to one guiding question, deliberately scoped to fit a large index card rather than a full paragraph. If a block needs three paragraphs, the chapter says that usually means the founder hasn't reached a clear enough answer yet — not that the tool is too small.

#### 4. Why does the chapter treat the canvas sprint's strict time limit as a feature rather than a shortcut?

<div class="upper-alpha" markdown>
1. Because a strict time limit guarantees the answer will be error-free
2. Because it prevents any peer from reviewing the block before the next session
3. Because the clock forces a founder to write an honest first-pass answer instead of endlessly polishing one block while the rest of the canvas sits empty
4. Because it replaces the need for a Field Discovery Window that week
</div>

??? question "Show Answer"
    The correct answer is **C**. A canvas sprint is a timed, focused group exercise — typically 5 to 10 minutes per block — where participants draft an answer individually before comparing with a peer. The time limit is a feature: it forces an honest first-pass answer instead of endlessly polishing one block while the rest of the canvas sits empty, exactly the idea-trap behavior Chapter 1 warned against.

#### 16. A canvas names "busy working parents" as the Customer Block but lists "flyers posted at the senior center" as the Distribution Block. What does canvas synthesis reveal about this canvas?

<div class="upper-alpha" markdown>
1. The blocks don't add up as one coherent argument — the message will never reach the customer it claims to be for
2. Nothing is wrong, since each block is individually a reasonable, complete answer
3. The canvas simply needs a longer Costs Block to resolve the mismatch
4. The mismatch only matters if the venture is B2B rather than B2C
</div>

??? question "Show Answer"
    The correct answer is **A**. Canvas synthesis is reading all 11 completed blocks together as one coherent argument, checking that each block's answer supports its neighbors rather than contradicting them. A Customer block naming "busy working parents" paired with a Distribution block of "flyers at the senior center" is exactly the mismatch synthesis catches — the message would never reach the stated customer.
