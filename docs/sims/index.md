# List of MicroSims for The Eight-Hour Entrepreneur

Interactive Micro Simulations to help students learn the eight-hour entrepreneur fundamentals.

<div class="grid cards" markdown>

-   **[30-Day Launch Roadmap Timeline](./thirty-day-launch-roadmap-timeline/index.md)**

    ![30-Day Launch Roadmap Timeline](./thirty-day-launch-roadmap-timeline/thirty-day-launch-roadmap-timeline.png)

    Learners can explain what each week of a 30-day launch roadmap accomplishes and how weekly milestones build toward launch readiness, using Jordan's plan as a concrete worked example.

-   **[Assumption Ledger Sorter](./assumption-ledger-sorter/index.md)**

    ![Assumption Ledger Sorter](./assumption-ledger-sorter/assumption-ledger-sorter.png)

    A six-card sorting quiz in which learners classify statements from Jordan's dog-grooming idea as either untested assumptions or validated learning, with immediate feedback on every card.

-   **[Benefit vs Advantage Sorter](./benefit-vs-advantage-sorter/index.md)**

    ![Benefit vs Advantage Sorter](./benefit-vs-advantage-sorter/benefit-vs-advantage-sorter.png)

    Given short value-proposition statements, learners classify each as a customer benefit statement (why the customer wants it) or a founder advantage statement (why this founder can deliver it), applying the chapter's definitions.

-   **[Break-Even Calculator](./break-even-calculator/index.md)**

    ![Break-Even Calculator](./break-even-calculator/break-even-calculator.png)

    Learners adjust price, per-sale cost, and fixed monthly cost sliders and calculate how many sales are needed to reach break-even for a lean venture.

-   **[CO.STARTERS Canvas Explorer](./costarters-canvas-explorer/index.md)**

    ![CO.STARTERS Canvas Explorer](./costarters-canvas-explorer/costarters-canvas-explorer.png)

    Learners can explain the guiding question each of the 11 CO.STARTERS Canvas blocks answers, and locate an example answer for each, by clicking through the full canvas layout.

-   **[Cohort Safety Signal Sorter](./cohort-safety-signal-sorter/index.md)**

    ![Cohort Safety Signal Sorter](./cohort-safety-signal-sorter/cohort-safety-signal-sorter.png)

    Given short statements describing things said or done during a cohort session, learners classify each one as "Safety-Building" or "Safety-Eroding," applying the chapter's definition of psychological safety to concrete cohort moments.

-   **[Competitive Landscape Map](./competitive-landscape-map/index.md)**

    ![Competitive Landscape Map](./competitive-landscape-map/competitive-landscape-map.png)

    Learners differentiate existing alternatives to a venture as the do-nothing alternative, a current workaround, an indirect competitor or substitute, or a direct competitor, by their directness in solving the same problem.

-   **[Customer Definition Funnel](./customer-definition-funnel/index.md)**

    ![Customer Definition Funnel](./customer-definition-funnel/customer-definition-funnel.png)

    Learners can explain how a broad market narrows step by step into a target customer, ideal customer profile, and persona, and can locate a concrete example at each stage.

-   **[Distribution Channel Map](./distribution-channel-map/index.md)**

    ![Distribution Channel Map](./distribution-channel-map/distribution-channel-map.png)

    Learners compare distribution channels by plotting channel cost against channel reach, analyzing the tradeoff to judge which channels best fit an early-stage venture with limited resources.

-   **[Leading vs Open-Ended Question Sorter](./leading-vs-open-ended-sorter/index.md)**

    ![Leading vs Open-Ended Question Sorter](./leading-vs-open-ended-sorter/leading-vs-open-ended-sorter.png)

    Given sample interview questions, learners classify each as open-ended or leading, applying the chapter's unbiased interview design principles.

-   **[Minimum Testable Iteration Decision Tree](./minimum-testable-iteration-decision-tree/index.md)**

    ![Minimum Testable Iteration Decision Tree](./minimum-testable-iteration-decision-tree/minimum-testable-iteration-decision-tree.png)

    Given a venture scenario, learners evaluate which lean-test principles (service before product, manual before automated, pre-selling before building) apply, and justify a resulting minimum testable iteration design.

-   **[Minimum Viable Offer Slider](./minimum-viable-offer-slider/index.md)**

    ![Minimum Viable Offer Slider](./minimum-viable-offer-slider/minimum-viable-offer-slider.png)

    Learners adjust an offer's scope using a slider and observe which features of a draft business idea are essential to the core offering versus removable, applying the concept of a minimum viable offer to a concrete example.

-   **[One-Sentence Value Proposition Builder](./one-sentence-value-proposition-builder/index.md)**

    ![One-Sentence Value Proposition Builder](./one-sentence-value-proposition-builder/one-sentence-value-proposition-builder.png)

    Learners compose a one-sentence value proposition by selecting from component options for target customer, core benefit, founder advantage, and main alternative, and observe the assembled sentence update live.

-   **[Persevere vs Pivot Signal Checker](./persevere-vs-pivot-signal-checker/index.md)**

    ![Persevere vs Pivot Signal Checker](./persevere-vs-pivot-signal-checker/persevere-vs-pivot-signal-checker.png)

    Given a set of validation evidence signals for a venture scenario, learners evaluate the pattern and justify whether it supports a persevere decision, a pivot decision, or a kill decision (from Chapter 10).

-   **[Startup Needs Sorter](./startup-needs-sorter/index.md)**

    ![Startup Needs Sorter](./startup-needs-sorter/startup-needs-sorter.png)

    Given a list of items a founder is considering purchasing, learners classify each as a genuine one-time need or a want that can wait, applying the needs-vs-wants assessment to a concrete example.

-   **[Symptom vs Root Cause Drill-Down](./symptom-root-cause-drilldown/index.md)**

    ![Symptom vs Root Cause Drill-Down](./symptom-root-cause-drilldown/symptom-root-cause-drilldown.png)

    Given a customer's first-stated complaint, learners apply a repeated "why" technique, choosing at each step which underlying cause to pursue, to trace the symptom down to its root cause.

-   **[The Field Discovery Window Rhythm](./field-discovery-window-rhythm/index.md)**

    ![The Field Discovery Window Rhythm](./field-discovery-window-rhythm/field-discovery-window-rhythm.png)

    Learners can explain what happens during each live session and each Field Discovery Window across the four-week course, and describe the relationship between the two (live instruction versus real-world testing).

-   **[The Four-Phase Founder Pipeline](./four-phase-founder-pipeline/index.md)**

    ![The Four-Phase Founder Pipeline](./four-phase-founder-pipeline/four-phase-founder-pipeline.png)

    A step-through infographic of the Clarity, Validation, Action, and Launch phases, pairing each definition with Jordan's concrete example and a predict-before-you-advance prompt.

-   **[The Idea Trap Cycle](./idea-trap-cycle/index.md)**

    ![The Idea Trap Cycle](./idea-trap-cycle/idea-trap-cycle.png)

    An interactive diagram that contrasts the closed "refine the plan" loop with the open "real-world test" path, using counters to show that only testing produces real customer answers.

-   **[Two-Minute Pitch Structure and Timer](./two-minute-pitch-structure-timer/index.md)**

    ![Two-Minute Pitch Structure and Timer](./two-minute-pitch-structure-timer/two-minute-pitch-structure-timer.png)

    Learners apply a four-part structure to organize and time a two-minute founder pitch, using Jordan's example to see what content belongs in each segment.

</div>
