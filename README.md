## Overview

**The Eight-Hour Entrepreneur** is an interactive intelligent textbook for an intensive, virtual "learning lab." It takes early-stage entrepreneurs from an unrefined idea to a validated, launch-ready venture in eight total hours, delivered as four 2-hour live sessions spread over four weeks. It is built for adult professional-development cohorts and requires no prior business, startup, or entrepreneurship experience. Participants only need to arrive with an unrefined idea they want to test.

The course operationalizes a single philosophy — **Clarity → Validation → Action → Launch** — around all 11 building blocks of the **CO.STARTERS Canvas** (Customer, Problem, Solution, Alternatives, Benefit, Advantage, Message, Distribution, Revenue, Startup Needs, Costs).

Seven-day gaps between sessions act as "Field Discovery Windows," pushing founders out of the idea trap and into real conversations with prospective customers before they build anything. Rather than a multi-year business plan, the outcome is a milestone-driven **30-day launch plan** backed by peer accountability and lean, low-capital validation methods.

The book is built as a **Level 2+ intelligent textbook**: a learning graph of 300 interconnected concepts drives prerequisite-ordered chapters, each paired with an interactive MicroSim, a glossary entry set, a quiz, and a curated, annotated reference list. Content was generated and curated with [Claude AI](https://claude.ai) skills on top of MkDocs Material, following the 2001 revision of Bloom's Taxonomy for its learning outcomes.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/dmccreary/eight-hour-entrepreneur.git
cd eight-hour-entrepreneur
```

### Installation

This project uses MkDocs with the Material theme:

```bash
pip install mkdocs mkdocs-material
```

### Build and Serve Locally

Build the static site:

```bash
mkdocs build --strict
```

Serve locally with live reload:

```bash
mkdocs serve
```

Then open `http://localhost:8000` in your browser.

### Deploy to GitHub Pages

```bash
mkdocs gh-deploy
```

This builds the site and pushes it to the `gh-pages` branch.

### Usage

- Use the left sidebar to browse the 17 chapters, each with **Content**, **Quiz**, and **Annotated References** pages.
- Each chapter embeds one or more interactive **MicroSims** (p5.js simulations) — try the sliders, buttons, and drag-and-drop sorters directly in the page.
- The **Learning Graph** section documents the 300-concept dependency graph, taxonomy, and quality/coverage reports behind the chapter sequencing.
- Browse the **Glossary** and **FAQ** for quick lookups, or the **Course Description** for the full Bloom's Taxonomy learning outcomes.
